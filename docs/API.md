## Verified acceptance cases

Specification basis. Sign family rebuilding plan, SignChain holds rules and order over admitted cells. A positive rule requires its antecedent at the declared knowledge reading.

| Case | Check | Behavior |
| --- | --- | --- |
| ` SCH-RULE-GUARD ` | source invariant | An absent antecedent produces no consequence. |
| ` SCH-RULE-READING ` | source refusal | Rule construction refuses an unknown knowledge reading. |
| ` SCH-RULE-QUICKSTART ` | consumer example | An affirmed premise fires its rule and produces the expected consequence. |

Runtime requirement. ` >=24.2.0 `
