## Architecture and contracts

SignCell distinguishes predication identity from the two exact witness sets. Obsmetrologia's FOUR evidence model licenses deriving a reading from lane presence, comparing readings in the knowledge order, and calculating the consequent's lanes. Metrologic implements those operations. The address system supplies exact identity for evidence and event receipts and coincidence keys for selecting predications. SignChain composes these operations into ordered histories, replica projections and rule application. The replica repair protocol and occurrence identity are engineering constructions. A host attests correspondence to an external observation and carries transport, persistence and authority.

`TellingLog` owns append order and its role indexes. It admits and retains one row before inserting it, and a sealed log refuses append. The indexed read selects the smallest applicable role bucket and checks a supplied read budget before visiting candidates. `cells`, the evidence comparison and the FOUR read derive their own views from admitted rows. `appendCellWitnesses` adds a receipt only after the log admits the telling. The receipt key commits to predication, polarity and exact witness. Source occurrences in replica receipts are independent of that witness key.

The replicated library was introduced in the local 0.7 candidate. Its v1 event digest identifies exact retained data. Address order gives deterministic replica and projection iteration. A host with authenticated producer order carries that order independently. A source occurrence uses two nonempty strings, `source` and `id`, supplied and authenticated at the host boundary. Distinct event occurrences can carry the same witness, which the SignCell projection gathers only once. The address-verified event set retains conflicts for later union and audit. The effective projection excludes conflicts and any repairs depending on them.

`fireRule` builds a valuation by admitting cells and joining duplicate predications. `fireRuleIn` accepts a caller-owned index and admits each consulted entry under its own cell address. A missing premise has the least knowledge reading. Each threshold must hold before the consequent is projected. Version 1 derivations retain the original name and premise trace. Version 2 also commits to the admitted rule. SignCraft uses that trace during settlement. SignGraph receives the evidence order and the existing token-frame and schema projections. Schema composition denotes an equal codomain/domain cut, and the host separately binds a source to its typed operation and authorized effect.
