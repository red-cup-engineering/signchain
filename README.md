# signchain
Witnessed rules, evidence ordering and executable SignCell contracts; one canonical SignChain package owner.


## Mark-rooted evidence, two orders and the identification frontier

SignChain consumes generated **SignCell** Mark/Utterance/predication cells.
It does not create the original marks, spatial geometry, lawfully attached
faces, or a free equivalence relation between two mark presentations.

The two evidence lanes are independently *told for* and *told against*.
The two order structures are the knowledge and truth readings over the
same generated FOUR carrier. Contradictory testimony must remain visible:
a `stable` knowledge charge records both evidence sides, rather than
collapsing to a Boolean true or false. Knowledge join/meet and truth
join/meet retain all original witness sources, even when their **value**
is no longer the directly measured evidence readout.

The original `bilattice.mjs` now exposes
`adjudicateCellEvidence(originalCell)`: a strictly finite, source-owned
judgment that separately reports the original *evidence reading*,
the written *value reading*, knowledge, truth, measurement agreement,
and one of `unobserved`, `supported-unopposed`,
`opposed-unopposed`, or `contested`. A supported observation is
only **eligible for a competent relation proof**. It is not such a
proof: `quotientAdmitted` remains false, including positive cases.
An explicit `Quot.sound` requires a proved equivalence relation;
one presented Mark coinciding with another as a byte string cannot
supply it. The current SignGraph `mark-gluing` conditional entrance
refuses opposed, contested, unmeasured or unobserved relations.

## Executable schema-borne fiber programs

The [fiber-program](docs/fiber-program.md) interface evaluates a typed recursive
[JSON program schema](data/schema/fiber-program.schema.json) against the original
generated SignCell token frame. It **computes** both truth- and knowledge-order
indexed adjoints, multiplicative linear tensor/par/residuation, and finite
enumerated-family quantification by reusing the original Data FOUR and SignChain
fibers. It does not import a second logic engine or derive source Marks.

The program's finite result is not a transfinite closure certificate or a
claim that every possible causal descent has been enumerated. Scientific
requirements and higher-regime proof obligations live with
[Lenticule Computer Science](https://github.com/lenticule-science/computer-science-services-section/blob/chatgpt-web/schema-borne-regime-lift-science-20261017/research/regime-lift-computing/2026-10-17-schema-borne-dual-order-linear-computing.md).
